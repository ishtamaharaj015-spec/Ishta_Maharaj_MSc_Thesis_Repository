# Ishta_Maharaj_MSc_Thesis_Repository
This repository contains the complete Python 3.13 workflow and all Excel data files used in the MSc thesis titled "Detailed bedrock morphology and structural geology controls on diamond traps offshore Hottentot's Bay, southern Namibia".

The Python workflow is titled "MSc_workflow.py" and includes several functions that cover the following:
1. Descriptive statistics of the digitised lineament data.
2. Plots of the length and orientation of the lineaments.
3. Descriptive statistics on the fault data and various sets of secondary lineaments
4. Analyses of the borehole data utilised in this study.
5. Plots that examine the relationships between various borehole parameters and the distribution of alluvial diamonds.
6. The machine learning algorithms applied in this study.

The Excel file containing the lineament data utilised in this study has been uploaded as "Lineament data.xlsx".

The Excel file containing the borehole data used in this study has been uploaded as "Borehole data.xlsx"

The combined geodataframe utilised in building the machine learning algorithms has been uploaded as "Combined geodataframe.xlsx"
